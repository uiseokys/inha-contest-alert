소유자 인증 필요

이 사이트가 사용하는 ntfy 채널의 공통 설정입니다. 페이지에서 선택한 뒤 GitHub에 로그인하여 요청 이슈를 제출하면, 저장소 소유자의 요청만 적용됩니다. 토픽·비밀번호를 이 페이지에 입력하지 마세요.

서버가 20분 간격으로 설정을 확인하고 알림 전에 수집합니다. 정확한 정시 수신은 보장되지 않습니다. 오늘 알림을 이미 예약·시도한 뒤 시간을 바꾸면 다음 날부터 적용됩니다.

기술 분야 필터가 하나 선택되어 있으면 해당 분야의 신규 건수도 브리핑에 추가합니다. 브라우저 관심 저장만으로는 서버 알림 설정이 바뀌지 않습니다.

공고 직접 추가 · 정보 수정

원문 근거를 확인한 공개 정보만 등록하세요.

소유자가 직접 제출한 요청은 자동 반영됩니다. 다른 사용자의 제안은 소유자 검토 후 재제출해야 합니다. 입력 URL을 무조건 방문하는 수집기는 아니며, 확인한 공개 정보를 수동 카드로 추가합니다.
