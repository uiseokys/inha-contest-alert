# 공모전 모아보기

인하대 게시판·캠퍼스픽·AI 대회 플랫폼을 모아서 보는 **개인용 무료 프로젝트**입니다.

**처음에는 [SETUP.md](SETUP.md)를 읽으세요.** 이 파일 묶음만 받아서는 아직 수집·알림이 작동하지 않습니다. 본인 GitHub에 업로드하고 Pages 및 ntfy 설정을 해야 합니다.

- 일일 수집: **한국시간 11:40 시작** → ntfy에 **12:00 예약 전달**. 지연 시 완료 후 발송.
- 알림: **어제 대비 신규 수·출처별 건수·변경 공고**를 포함하며, 신규가 없는 날도 1회 요약. 수동 목록 갱신은 기본 무알림.
- 목록: GitHub의 아래 표와 GitHub Pages의 검색·필터 페이지. **접수기간 / 대회기간 / 주최기관 / 참가 대상 / 안내·신청 링크**를 확인합니다.
- 캠퍼스픽: 공개 공모전의 제목·카드에서 AI·데이터·통계 관련 표현을 선별합니다.
- 기본 정렬: **마감 여유순** → 미확인 → 이미 마감. 카드 제목 최대 2줄, 전체 제목은 상세에서 확인.
- 상세정보: 웹페이지의 **일정·참가 정보 펼치기**. 확인 불가 항목은 미확인으로 표시합니다.
- v3 → v4 교체: [UPGRADE.md](UPGRADE.md). 기존 `data/state.json`은 보존하세요.
- 실행: 공개 저장소의 표준 GitHub-hosted Ubuntu runner. 유료 AI API·서버·DB·도메인 없음.
- 보안: 공개 목록에 개인정보를 넣지 마세요. ntfy 토픽은 `NTFY_TOPIC` Secret에만 등록합니다.

> **검증 범위:** 오프라인 파서·날짜·중복 방지·알림 프로토콜·화면 테스트를 제공합니다. 현재 검증 범위와 결과는 [검증 보고서](docs/TEST_REPORT.md)에 기록했습니다. 실제 GitHub 환경에서 각 사이트(캠퍼스픽 포함)의 수집과 Pages 배포, 휴대폰 수신까지 검증된 상태는 아닙니다. 학과 사이트의 접근/HTML 변경이 있으면 수집 상태에 오류가 표시됩니다. 설치 후 반드시 출처별 성공 여부를 확인하세요.

## 어제 대비 신규 기준

전날 마지막 저장 목록과 최근 수집 목록을 공고 주소로 비교합니다. 첫 실행/업데이트 직후에는 비교 준비 중, 전날 누락이면 실제 기준 날짜, 수집 실패면 비교 불가 또는 부분 집계를 표시합니다. 다른 출처에 재게시된 같은 대회는 별도로 셀 수 있습니다.

디자인 적용 근거: [DESIGN_APPLICATION.md](docs/DESIGN_APPLICATION.md).

## 파일 역할

`config.json`은 출처와 수집 범위, `contest_alert/`는 수집·기록·알림 프로그램, `web/`은 화면, `data/state.json`은 누적 상태, `site/`는 생성된 공개 페이지입니다. `.github/workflows/daily.yml`이 클라우드 실행을 담당합니다.

테스트: `python -m unittest discover -s tests -v`

## 주의

공식 대회 안내 서비스가 아니라 개인용 수집기입니다. 정시 실행·전수 수집·실제 알림 수신은 보장하지 않습니다. 동일 URL을 중복 제거하며, 서로 다른 URL로 재게시된 같은 대회는 별도로 나타날 수 있습니다. 공개 페이지의 일부만 수집하고 첨부 포스터/PDF/HWP를 자동 해석하지 않으므로 마감일이 ‘미확인’으로 남을 수 있습니다.
