## 어제 대비 신규 기준

전날 마지막 저장 목록과 최근 수집 목록을 공고 주소로 비교합니다. 첫 실행/업데이트 직후에는 비교 준비 중, 전날 누락이면 실제 기준 날짜, 수집 실패면 비교 불가 또는 부분 집계를 표시합니다. 다른 출처에 재게시된 같은 대회는 별도로 셀 수 있습니다.

디자인 적용 근거: [DESIGN_APPLICATION.md](docs/DESIGN_APPLICATION.md).

## 파일 역할

`config.json`은 출처와 수집 범위, `contest_alert/`는 수집·기록·알림 프로그램, `web/`은 화면, `data/state.json`은 누적 상태, `site/`는 생성된 공개 페이지입니다. `.github/workflows/daily.yml`이 클라우드 실행을 담당합니다.

테스트: `python -m unittest discover -s tests -v`

## 주의

공식 대회 안내 서비스가 아니라 개인용 수집기입니다. 정시 실행·전수 수집·실제 알림 수신은 보장하지 않습니다. 동일 URL을 중복 제거하며, 서로 다른 URL로 재게시된 같은 대회는 별도로 나타날 수 있습니다. 공개 페이지의 일부만 수집하고 첨부 포스터/PDF/HWP를 자동 해석하지 않으므로 마감일이 ‘미확인’으로 남을 수 있습니다.
