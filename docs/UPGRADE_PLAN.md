요구사항: 기존 무료 GitHub Actions/Pages/ntfy 구성을 유지한다. PC 전원에 의존하지 않는 cloud runner와 정오 일일 브리핑은 변경하지 않는다. 캠퍼스픽의 공개 AI/데이터 공고를 수집 대상으로 추가하고, 웹/README/CSV에서 접수기간과 실제 대회기간, 주최기관, 참가 대상, 안내/신청 링크, 짧은 공개 요약을 확인한다.

구현: 기존 프로젝트 수정. 별도 계정 연결/외부 배포/푸시 발송은 하지 않는다. HTML의 공개 링크만 읽고 robots/인증 차단을 존중한다. 비공개 API는 사용하지 않는다. 명시된 필드만 추출하고 여러 접수차수/연도 불명/이미지 전용 정보는 미확인으로 남긴다. 상세 읽기 실패 시 이전 자료를 보존하고 확인 상태를 표시한다.

1. 기존 39개 테스트 확인 (완료).
2. 캠퍼스픽 URL·AI 필터·기간·필드 보존 테스트를 먼저 실행해 미구현 실패 확인.
3. 공개 HTML 파서/상세정보 추출/수집기 연동, 출처별 상세 읽기 예산 배분.
4. 상세정보 펼치기, 접수기간 바로 표시, 검색 확장, README/CSV 확장.
5. 가상 데이터 미리보기 및 화면 테스트, 운영 데이터 비우기, 업그레이드 안내와 검증 기록.

직접 확인된 공개 웹: https://www.campuspick.com/contest 와 robots.txt. 공개 목록의 /contest/view?id=숫자 링크를 확인했다. 세부 HTML은 웹 도구에서 본문이 비었으며 컨테이너 DNS 연결도 실패했다. 합성 HTML 검증과 실제 서비스 운영 검증을 구분해 보고한다.
