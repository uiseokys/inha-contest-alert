# 공모전 모아보기 — v0.1 설계

## 목표
공용 ChatGPT와 분리한다. 무료 공개 GitHub 저장소에서 공고 수집, GitHub README와 정적 웹페이지 갱신, 개인 ntfy 일일 요약을 수행한다. 컴퓨터는 꺼져 있어도 된다.

## 동작
한국시간 11:40 수집 시작(UTC 02:40), ntfy의 예약 전달 기능으로 같은 날 12:00 목표 발송. 작업이 늦으면 그날 즉시 보내되 지연 표시. GitHub 및 ntfy의 서비스 지연/장애로 정시/수신을 보장하지 않는다. 매일 신규 0건이어도 한 메시지. 수동 목록 갱신은 기본 무알림. 날짜별 선점 기록을 원격 저장소에 먼저 저장한 뒤 전송해 재실행 중복을 억제한다. 선점 뒤 중단되면 그날 알림을 놓칠 수 있으며 자동 재전송하지 않는다.

## 목록
제목/출처/게시일(있을 때)/접수마감(명시적 문맥일 때)/원문/첫 발견일/수집 상태. 검색, 출처·상태·신규 필터, 최신/마감 정렬, CSV, 모바일 대응. GitHub README에는 동일 데이터 요약. 없는 마감일과 참가자격은 만들지 않는다. 동일 URL만 확실하게 중복 제거; 다른 게시판에 재게시된 같은 대회의 의미적 병합은 하지 않는다. '인하대 게시판'은 '교내 대회만'이라는 뜻이 아니다.

## 수집 및 공개 범위
설정된 공개 게시판 일부 페이지만 수집. 인하대 DS/AI/AIX/SW, 대학 홈페이지, DACON, AI Factory. 대학 홈페이지에서 공지 게시판 링크 발견을 시도. 정적 HTML 우선, 선택적 Chromium으로 공개 페이지 렌더링. robots.txt 준수; 403/429/인증벽 우회 금지. 실패는 명시하고 기존 목록 유지. 목록에 없어진 글을 종료로 단정하지 않는다. 날짜 추출은 접수/신청/모집 문맥의 명확한 연도 포함 날짜만. 원문 본문/포스터는 저장하지 않고 짧은 제목, 날짜, 링크만 공개한다.

## 비밀과 비용
GitHub Pages 무료 사용을 위한 공개 저장소가 기본. ntfy 토픽은 GitHub Secret만 사용하며 공개 출력/오류/브라우저 코드에 넣지 않는다. 유료 API, 외부 DB, 유료 도메인 없음. 사용자가 직접 본인 계정에 업로드·Secrets·Pages 설정을 해야 하며 이 세션에서는 배포/푸시/알림 발송하지 않는다.

## 검증 경계
로컬 환경의 외부 DNS가 제한되어 실제 Python 수집·GitHub 실행·폰 수신은 검증 불가. 공개 웹에서는 AIX/DACON/AI Factory 원문 링크 형식을 확인했고 일부 학과 주소는 접근 실패. 합성 HTML·HTTP 대역·브라우저로 파서/상태/보안/화면을 검증한다. 이 한계를 설치안내 및 최종 답변에 명시한다.
