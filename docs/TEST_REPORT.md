이 확인은 웹 도구로 읽은 원문에 한정됩니다. 제작 컨테이너의 외부 DNS/네트워크 제한으로 **Python 수집기로 실제 사이트를 요청하는 종단간 테스트는 수행하지 못했습니다.** CampusPick의 실제 동적 HTML, 인하대 robots/접근 조건, GitHub runner IP에서의 응답은 배포 후 확인해야 합니다. 현재 사용자 저장소 주소와 실제 state.json도 제공받지 않아 실제 날짜 확인율을 측정하지 않았습니다.

날짜가 포스터 이미지/PDF/HWP에만 있거나 로그인이 필요하면 미확인으로 남을 수 있습니다. 이미지 대체텍스트를 읽는 기능은 픽셀에서 글자를 읽는 OCR이 아닙니다. 연도를 제목에서 보완한 경우 그 근거를 표시하며, 게시일·오늘 날짜·D-day로 연도를 만들지 않습니다. 서로 충돌하는 접수기간은 확정하지 않습니다.

추가 요청에는 예산이 있습니다. 기본 설정은 주요 상세페이지 최대 30개, 추가 일정 요청 최대 18회, 추가 브라우저 확인 최대 8회이며 상세 단계의 소프트 시간 예산은 360초입니다. 진행 중인 한 요청까지 합치면 그 시간보다 길어질 수 있습니다. 모든 저장 공고가 한 번의 실행에서 새 파서로 갱신된다는 의미는 아닙니다.

정오 예약, 어제 대비 신규, 날짜별 최대 한 번 제출 시도 정책은 그대로 유지합니다. 수신 정시성/정확히 1회/전수 수집은 보장하지 않습니다.
