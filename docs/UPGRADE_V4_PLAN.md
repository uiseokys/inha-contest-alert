# v4: 날짜 추출·제목 정규화·여유 있는 마감순

사용자 요청: 누락된 접수 시작/마감 개선, 출처별 제목/표시 형식 통일, 마감이 많이 남은 순을 기본 정렬로 변경. 기존 디자인·정오 ntfy·전날 비교·사용자 저장 기록 보존.

확인한 원인: 제한적인 라벨/날짜 정규식, 일반 div 및 플랫폼 루트 미인식, 개요만 요청하고 일정 탭 미추적, 주최만 추출해도 JS 보완 생략, 3일 재확인 대기, 목록 전체 텍스트의 제목 혼입.

실행 순서:
1. 날짜/제목/수집 회귀 테스트를 먼저 작성하고 v3에서 실패 확인.
2. 접수 라벨/괄호/요일/공백/생략연도(명시된 문맥만)/시작·종료 개별 항목 및 중복 구간 지원. 행사기간과 혼동 금지. 날짜 근거 URL·사유 저장.
3. 본문 범위 확장 및 같은 공고 일정 링크를 한 단계만 추가 확인. 날짜 누락 시 제한된 브라우저 보완. 파서 v4 최초 갱신 및 일별 미확인 재확인. 접근 차단 우회 금지.
4. 순수 제목 추출, 장문은 카드 2줄/상세 전체 제목. 통일된 접수 시작·마감 표시. 기본 정렬은 유효 미래 마감 내림차순 → 미확인 → 이미 마감. 최신/임박순 선택은 유지.
5. Python/JS/모바일·데스크톱 검증, 기존 v3 위 업데이트 병합 검증, 전체 및 상태 미포함 업데이트 ZIP.

확인 범위: 실제 공개 웹 일정 텍스트는 확인했으나 컨테이너 DNS 제한으로 직접 HTTP 수집 불가. 임의로 날짜를 채우지 않으며 이미지/OCR/첨부 추출은 이번 변경에 포함하지 않음.
