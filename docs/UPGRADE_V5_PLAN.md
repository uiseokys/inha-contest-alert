# v5 오류 수정 계획 (2026-09-22)

사용자 요구: 실패하는 인하대 대표 공지는 복구 불가하면 제외, 센터의 게시글 제목 복구,
마감일시 추출 개선, AI/데이터와 무관한 공모전·프로그램 제외. 무료 실행·정오 1회·기존 디자인·
마감 여유순·어제 대비 집계는 유지. 운영 저장소/상태는 미제공; 제공된 v4가 기준.

## 확인한 원인
- _title은 generic h1/og:title을 실제 게시글 제목보다 먼저 사용. 기존 detail_title을 계속 우선함.
- 본문 정제에서 form을 통째로 삭제할 수 있음. 게시판 본문이 form 안이면 정보가 사라짐.
- 모든 교내 source의 mode=contest; 대회 여부만 검사하고 AI/데이터 근거 불필요.
- 날짜는 4자리 연도만 인식; 실제 AIX vid=107 접수기간은 '26. 7. 16 ~ 8. 17 형식.
- 공식 접수처의 다른 플랫폼 링크를 확인하지 않고, 날짜가 들어간 공개 구조화 데이터도 미지원.

## 순서와 검증
1. 제목/본문/접수일시 회귀 테스트 RED → 구현 GREEN.
2. 관련성 판정·대표 홈페이지 제외·기존 기록 보존 및 비노출 테스트 RED → GREEN.
3. 수집기에 결합; 동일 공고의 공식 접수처 한 단계 확인 및 근거 링크 표시.
4. 전체 기존 테스트, 날짜/정렬/알림 회귀·브라우저 검사. 자체 검토.
5. state/config/workflow/README를 덮어쓰지 않는 업데이트 ZIP 및 전체 ZIP 검증.

## 판단
- 인하대 대표 홈페이지는 공개 웹에서도 502/접근 오류. 기본 자동수집에서 제외하고
  수동 확인 링크만 유지. 학과/AIX/SW는 유지. 이전 config를 직접 덮어쓰지 않고 런타임 기본 적용.
- AI 관련 영상 공모전도 AI 활용이 주제이면 포함. 단순 AI 사용금지 문구나 기관 이름만으로 포함하지 않음.
- 보수적 미확인 유지: 이미지/PDF/HWP 픽셀 OCR, 숨겨진 API, 로그인/차단 우회는 추가하지 않음.
- 운영 접속 성공률·정시수신은 검증되지 않음. 네트워크 오류를 0건으로 가장하지 않음.

- 검토 판단: 캠퍼스픽은 전체 분야 플랫폼이므로 제목/카드 AI·데이터 1차 선별을 유지한다.
  모든 항목을 후보로 가져오면 무관한 공고가 제한된 상세 요청을 소진한다. 이후 본문에서 재검증한다.
  DACON/인공지능팩토리는 제목에 AI가 없어도 상세 주제를 읽는 후보로 유지한다.

## 최종 자체 검토 수정
- 날짜만 있는 원문도 명시된 공식 일정 링크에서 마감 시각을 보완. 링크 없는 날짜 완비 공고는 추가 브라우저 요청을 강제하지 않는다.
- 서로 다른 접수 시각이 공존하면 날짜는 보존하되 시각을 미확인으로 처리하고 이전의 확정 시각도 제거.
- AI 융합연구센터처럼 띄어쓴 페이지 제목은 게시글 제목으로 사용하지 않음.
- 위 4개 테스트의 실패를 재현 후 수정, 전체 테스트 재실행.
